# Text-to-Video Generator

Автоматизированная система для создания видеороликов из текстовых сценариев с использованием локальной генерации речи, автоматических субтитров и фоновой музыки.

## 🎯 Возможности

- ✅ **Локальная генерация речи** с помощью Coqui TTS (без облачных API)
- ✅ **Автоматическая синхронизация субтитров** с точными таймингами
- ✅ **Поддержка различных форматов видео**: 16:9, 9:16, 1:1, 4:3, 21:9
- ✅ **Фоновая музыка** с регулировкой громкости и fade-эффектами
- ✅ **Настройка через YAML** конфигурацию
- ✅ **Мощный CLI интерфейс** с 14 параметрами
- ✅ **Многоязычность**: Русский и Английский
- ✅ **Система логирования** для отладки
- ✅ **Обработка ошибок** с информативными сообщениями
- ✅ **247 тестов** с 99% покрытием кода

## 🚀 Быстрый старт

### Требования

- Python 3.9+
- FFmpeg (установлен и доступен в PATH)
- 4-8 GB RAM

### Установка

```bash
# Клонировать репозиторий
git clone <repository-url>
cd text2video

# Создать виртуальное окружение
python3 -m venv venv
source venv/bin/activate  # Linux/macOS
# или
venv\Scripts\activate     # Windows

# Установить зависимости
pip install -r requirements.txt

# Проверить установку FFmpeg
ffmpeg -version
```

### Использование

```bash
# Базовое использование
python main.py --input script.txt --output video.mp4

# С кастомной конфигурацией
python main.py -i script.txt -o video.mp4 -c config.yaml

# Указать формат видео
python main.py -i script.txt --aspect-ratio 9:16

# Без фоновой музыки
python main.py -i script.txt --no-music

# Выбрать язык озвучки
python main.py -i script.txt --language en

# Выбрать голос для озвучки
python main.py -i script.txt --speaker male_deep

# Использовать кастомный голос
python main.py -i script.txt --speaker custom --speaker-audio path/to/voice.wav

# Использовать изображения по порядку (по именам файлов)
python main.py -i script.txt --image-mode ordered

# Показать версию
python main.py --version

# Минимальный вывод
python main.py -i script.txt --quiet

# Подробное логирование
python main.py -i script.txt --log-level DEBUG
```

### Все доступные параметры

| Параметр | Короткий | Описание | Значение по умолчанию |
|----------|----------|----------|------------------------|
| `--input` | `-i` | Путь к текстовому файлу (.txt или .md) | **Обязательный** |
| `--output` | `-o` | Путь для сохранения видео | `output/video_TIMESTAMP.mp4` |
| `--config` | `-c` | Путь к файлу конфигурации | `config.yaml` |
| `--aspect-ratio` | - | Соотношение сторон видео | `16:9` |
| `--resolution` | - | Разрешение видео (ШxВ) | `1920x1080` |
| `--language` | - | Язык озвучки (ru/en) | `ru` |
| `--speaker` | - | Выбор голоса (default/male_deep/female_soft/custom) | `default` |
| `--speaker-audio` | - | Путь к reference audio для custom голоса | - |
| `--image-mode` | - | Режим выбора изображений (random/ordered) | `random` |
| `--music-volume` | - | Громкость музыки (0.0-1.0) | `0.2` |
| `--no-music` | - | Отключить фоновую музыку | `false` |
| `--no-subtitles` | - | Отключить субтитры | `false` |
| `--log-level` | - | Уровень логирования | `INFO` |
| `--quiet` | - | Минимальный вывод | `false` |
| `--init` | - | Инициализировать TTS модели | `false` |
| `--version` | - | Показать версию | - |
| `--help` | `-h` | Показать справку | - |

## 🎬 Пример сценария

Создайте файл `script.txt`:

```
Добро пожаловать в мир автоматизации создания видео!
Эта система позволяет превратить любой текст в полноценный видеоролик.

Второй абзац становится второй сценой.
Каждая сцена получает свою озвучку и визуальное оформление.

Наслаждайтесь результатом!
```

Каждый абзац, разделённый пустой строкой, становится отдельной сценой в видео.

## ⚙️ Конфигурация

Основные настройки в `config.yaml`:

```yaml
# Настройки TTS
tts:
  language: "ru"  # ru | en
  speed: 1.0

# Настройки видео
video:
  fps: 30
  aspect_ratio: "16:9"  # 16:9 | 9:16 | 1:1
  resolution:
    width: 1920
    height: 1080

# Настройки субтитров
subtitles:
  enabled: true
  font_size: 48
  color: "white"
  max_chars_per_line: 40

# Настройки аудио
audio:
  music:
    enabled: true
    volume: 0.2  # Громкость относительно речи
```

## 🎙️ Выбор голоса (Voice Cloning)

Система поддерживает выбор различных голосов для озвучки с использованием технологии voice cloning от Coqui TTS XTTS v2.

### Доступные голоса

- **default** - Стандартный голос XTTS v2 (встроенный, не требует настройки)
- **male_deep** - Брутальный мужской голос для историй и повествования
- **female_soft** - Мягкий женский голос для обучающего контента
- **custom** - Ваш собственный голос (укажите path к WAV файлу)

### Использование

#### Через CLI:
```bash
# Использовать мужской брутальный голос
python main.py -i story.txt --speaker male_deep

# Использовать женский мягкий голос
python main.py -i tutorial.txt --speaker female_soft

# Использовать свой кастомный голос
python main.py -i script.txt --speaker custom --speaker-audio path/to/my_voice.wav
```

#### Через config.yaml:
```yaml
tts:
  language: "ru"
  speaker: "male_deep"  # default | male_deep | female_soft | custom
  speaker_audio:
    male_deep: "./assets/speakers/male_deep.wav"
    female_soft: "./assets/speakers/female_soft.wav"
    custom: null  # Указывается через CLI
```

### Добавление своего голоса

1. **Запишите аудио**: WAV формат, минимум 6 секунд, чистая запись без шумов
2. **Сохраните файл**: В директорию `assets/speakers/` с именем `male_deep.wav` или `female_soft.wav`
3. **Используйте**: Укажите `--speaker male_deep` при запуске

Подробные инструкции см. в `assets/speakers/README.md`

## 🖼️ Управление порядком изображений

Система поддерживает два режима выбора изображений для сцен:

### Режим Random (по умолчанию)
Изображения выбираются случайным образом из директории `assets/images/` для каждой сцены.

### Режим Ordered (упорядоченный)
Изображения выбираются по порядку на основе **номера сцены в имени файла**.

#### Поддерживаемые форматы имен файлов:

**Базовые форматы (номер сцены):**
- `1.jpg`, `2.jpg`, `3.jpg` - просто номер
- `scene-1.jpg`, `scene-2.jpg` - с префиксом "scene"

**С указанием длительности:**
- `1_5.jpg` - сцена 1, длительность 5 секунд
- `2_10.5.jpg` - сцена 2, длительность 10.5 секунд
- `scene-3_7.jpg` - сцена 3, длительность 7 секунд

#### Примеры использования:

```bash
# Через CLI
python main.py -i script.txt --image-mode ordered

# Через config.yaml
visuals:
  selection_mode: "ordered"
```

#### Как это работает:

1. **Номер сцены**: Система извлекает номер сцены из имени файла
2. **Сопоставление**: Изображение с номером N используется для сцены N
3. **Длительность** (опционально): Если указана в имени файла (например, `_5` для 5 секунд), она **переопределяет** длительность аудио для этой сцены

#### Пример структуры:

```
assets/images/
├── 1_3.jpg          # Сцена 1, показывается 3 секунды (независимо от аудио)
├── 2.jpg            # Сцена 2, длительность по аудио
├── scene-3_10.jpg   # Сцена 3, показывается 10 секунд
└── 4_5.5.jpg        # Сцена 4, показывается 5.5 секунд
```

#### Важные замечания:

- В ordered режиме **количество изображений должно соответствовать количеству сцен**
- Если изображение для сцены не найдено, будет ошибка с указанием недостающего номера
- Длительность из имени файла **переопределяет** длительность аудио
- Это полезно для создания пауз, замедления или ускорения показа определенных сцен

## 🐛 Устранение неполадок

### FFmpeg не найден
```bash
# macOS
brew install ffmpeg

# Ubuntu/Debian
sudo apt-get install ffmpeg

# Windows
# Скачать с https://ffmpeg.org/download.html и добавить в PATH
```

### Ошибка загрузки TTS модели
```bash
# Инициализировать модели вручную
python main.py --init
```

### Недостаточно памяти
- Уменьшите разрешение видео в config.yaml
- Разбейте длинный текст на несколько файлов
- Закройте другие приложения

### Проблемы с субтитрами
- Проверьте, что аудио корректно сгенерировано
- Убедитесь, что `duration` сцены установлена
- Используйте `--log-level DEBUG` для диагностики
