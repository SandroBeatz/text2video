# Speaker Audio Files / Аудиофайлы для голосов

Эта директория содержит reference audio файлы для voice cloning с помощью Coqui TTS XTTS v2.

## Требования к аудиофайлам


## Доступные голоса

Система поддерживает следующие варианты голосов:

### 1. **default** - Стандартный голос
- Встроенный голос XTTS v2 "Claribel Dervla"
- Не требует reference audio файла
- Универсальный голос среднего тона

### 2. **male_deep** - Брутальный мужской голос
- Файл: `male_deep.wav`
- Рекомендуется для: историй, повествования, документальных видео
- **Требуется**: Добавить ваш собственный аудиофайл

### 3. **female_soft** - Мягкий женский голос
- Файл: `female_soft.wav`
- Рекомендуется для: обучающих видео, дружелюбного контента
- **Требуется**: Добавить ваш собственный аудиофайл

### 4. **custom** - Кастомный голос
- Указывается через CLI параметр `--speaker-audio`
- Используйте любой WAV файл с вашим голосом

## Как добавить свой голос

### Вариант 1: Использовать предустановленные слоты

1. Запишите или найдите чистый аудиофайл (WAV, минимум 6 секунд)
2. Сохраните его в эту директорию:
   - `male_deep.wav` - для брутального мужского голоса
   - `female_soft.wav` - для мягкого женского голоса
3. Используйте в программе:
   ```bash
   python main.py -i script.txt --speaker male_deep
   ```

### Вариант 2: Использовать кастомный файл

1. Подготовьте WAV файл с записью голоса
2. Укажите путь к файлу через CLI:
   ```bash
   python main.py -i script.txt --speaker custom --speaker-audio /path/to/your/voice.wav
   ```

## Советы по записи голоса

1. **Тихое помещение**: Записывайте в помещении без эха и фонового шума
2. **Качественный микрофон**: Используйте хороший микрофон (даже встроенный в ноутбук подойдет)
3. **Естественная речь**: Говорите естественно, не слишком медленно и не слишком быстро
4. **Содержание**: Прочитайте несколько предложений на том языке, на котором будете генерировать видео
5. **Длительность**: 10-15 секунд оптимально, минимум 6 секунд
6. **Формат**: Сохраните как WAV (можете конвертировать из MP3 с помощью FFmpeg)

## Пример конвертации аудио

Если у вас есть MP3 файл, конвертируйте его в WAV:

```bash
ffmpeg -i input.mp3 -ar 22050 -ac 1 output.wav
```

## Где найти sample аудио

Вы можете:
1. **Записать свой голос** с помощью любого диктофона
2. **Использовать готовые записи**: Найти чистые аудио samples на [FreeSound.org](https://freesound.org)
3. **Голосовые сообщения**: Экспортировать из мессенджеров и конвертировать в WAV

## Примеры использования

### Базовое использование с предустановленным голосом
```bash
python main.py -i story.txt --speaker male_deep
```

### Использование кастомного голоса
```bash
python main.py -i script.txt --speaker custom --speaker-audio assets/speakers/my_voice.wav
```

### Настройка в config.yaml
```yaml
tts:
  language: "ru"
  speaker: "male_deep"  # default | male_deep | female_soft | custom
  speaker_audio:
    male_deep: "./assets/speakers/male_deep.wav"
    female_soft: "./assets/speakers/female_soft.wav"
```

## Устранение неполадок

### Ошибка: "Speaker audio file not found"
- Убедитесь, что файл существует по указанному пути
- Проверьте, что имя файла правильное (с учетом регистра)

### Ошибка: "Speaker audio is too short"
- Аудиофайл должен быть минимум 6 секунд
- Запишите более длинную фразу

### Плохое качество голоса
- Используйте более чистую запись без шумов
- Увеличьте длительность reference audio до 10-15 секунд
- Убедитесь, что формат WAV, а не сжатый MP3

## Технические детали

Voice cloning в XTTS v2 работает следующим образом:
- Модель анализирует reference audio файл
- Извлекает характеристики голоса (тембр, интонация, темп)
- Применяет эти характеристики при синтезе нового текста
- Результат: сгенерированная речь звучит похоже на голос из reference audio
